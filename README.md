# Пространство для Жизни · 168

Личный планировщик недели: календарь, жизненные сферы, задачи, таймер фокуса и аналитика распределения 168 часов.

## Запуск

Открой `index.html` в современном браузере. Приложение работает без сборки, сервера и внешних библиотек. Основные файлы: `index.html`, `style.css`, `app.js`.

Для GitHub Pages источник публикации — ветка `main`, корневая папка `/`. Файл `.nojekyll` отключает обработку статических файлов через Jekyll.

## Данные и резервные копии

Данные планировщика хранятся в localStorage браузера, а не в репозитории. Автоматической синхронизации между устройствами нет.

При переходе с локального файла на GitHub Pages откроется отдельное хранилище. Для переноса скачай JSON-копию в настройках старой версии и импортируй её в настройки опубликованной версии. Резервные копии с личными записями не нужно загружать в публичный репозиторий.

## Документы и проверки

- `plan.md` — план и история разработки.
- `audit.md` — аудит соответствия ТЗ и статус исправлений.
- `concept.md` — первоначальная концепция; актуальный объём разработки указан в плане.
- `tests/` — автоматические проверки и снимки тестового интерфейса.

Проверки логики выполняются через Node.js, например `node tests/audit-fixes.cjs`. Для браузерных сценариев нужен Playwright и соответствующий установленный браузер; тестовый сервер запускается командой `node tests/serve.cjs`. Эти инструменты нужны только для разработки и не требуются пользователю приложения.
